# runtime_reduced_v1.36

本版本发布已完成 19 组全程验证的稳定源码快照，基线发布提交为 9572835（v1.35-r1），验证核心 SHA256 为 0c68c5c51a0614d3f7c766bb96603c83871e7473fceca5eda3a77a179ecfc82d。

默认：原始鱼眼分辨率、四目、无人体 mask、无额外裁剪、GPU Schur FP64、最多四关键帧窗口、回环和 PGO 关闭。执行前保留 cam2/标定旋转自动检查。默认时移来自标定 YAML，额外 IMU 时移为 0。

- `FILE_CHANGES.md`：逐文件修改和原因。
- `results/REPORT.html`：最优稳定版本完整测试报告，包含六组真值数据及 Basalt 同机结果；诊断实验不混入最优版本比较。
- `audit/REPORT.html`：时间间隔、前后端和窗口审计；已知问题不宣称修复。
- `results/run_manifest.json`：19 组验证的原始运行命令与库哈希。
- 发布后从本提交重建的哈希、CTest 和全程逐帧一致性验证记录见共享运行包的 `manifest.json` 与 `release_validation/`。

## 修改范围

加入视觉初始化前的有效陀螺旋转初值、低支持观测时的跨相机匹配刷新与地图保留；保持初始化候选的视觉验收；窗口被拒绝时不保留未提交的局部地图/先验；补充实际鱼眼像素几何、三角化与数值转换验证；发布入口与已验证无掩模配置一致，并隔离继承的实验环境变量。部分几何匹配/数值对照接口仅供诊断，未启用为发布默认配置。

## 已知限制

201148 仍有 3.648 m/s 峰值，room 部分高度误差仍偏大；起终高度变化不能替代真值误差。旧 Cauchy 导数问题仍列为已知问题，实验修复造成高度退化所以未合入。滑窗地图支持检查的鱼眼像素近似和默认后验中的 float 转换仍待全程修复验证。不能将本版描述为所有速度/高度问题均解决。
