# v1.4 重力锚定窗口

基于 v1.33（`b69ecbf`，分支 `release/runtime_reduced_v1.33`）。版本字符串后缀为 `-v1.4_gravity_vvert`。本分支不改 v1.33 的发布包、`run_vio.sh` 或 `replay.py`。

已报告的测试只打开 `CUVSLAM_GRAVITY_ANCHOR=1`。不要设置 `CUVSLAM_GRAVITY_VZ` 或 `CUVSLAM_GRAVITY_SCHEME`。无回环和多路跨帧保持 v1.33。HALO 回放继续使用 v1.33 的 `replay.py`，其中 `CUVSLAM_WINDOW_SIZE=4`。

## 窗口与前端

`CUVSLAM_GRAVITY_ANCHOR=1` 时：

- 前端预积分信息只放大位置残差块。`libs/pipelines/gpu_window/gpu_joint_adapter.cpp` 对该 3×3 块乘 5，位置信息变为原来的 25 倍，即在原有 0.002 的基础上成为 0.05。旋转残差和速度残差仍用调用方的 penalty。位置–旋转、位置–速度交叉项乘 5。
- 窗口内预积分不再统一乘 0.002。`libs/pipelines/gpu_window/window_backend.cpp` 保持旋转对角为预积分原值；速度、位置对角以及速度–位置交叉为 0.05；旋转–速度、旋转–位置交叉为 √0.05 ≈ 0.224。陀螺随机游走权重为 1.0，加计随机游走权重为 0.05。未设置该开关时，窗口权重仍是 `0.002 * Info`。
- 滑出窗口的关键帧保留为冻结视角，最多 16 个。位姿固定，观测不进入边缘化先验，残差只约束地图点（`node = -1`）。与当前轨迹重叠最少的视角被丢掉；重叠相同时丢掉更早的。活动图被清空后，从地图最近 20 个关键帧里补回与当前轨迹至少共享 8 条 track 的视角。冻结视角不占用活动关键帧槽位。

活动槽位从 6 改为 8（120 维）。导航核仍是 128 线程，不再增加活动关键帧。`window_limit()` 在未设置 `CUVSLAM_WINDOW_SIZE` 时返回 8；显式设为 3 或 4 时仍返回该值。v1.33 的默认是 6。HALO 回放显式使用 4，活动窗口长度与 v1.33 相同。

## 惯性初始化

`libs/imu/inertial_optimization.cpp` 的线性对齐和重力细化改为双精度求解。初始化时用比力接近重力的样本估计参考重力方向，样本不足 50 个时退回全部样本；这个方向只作为 `RefineGravity` 的参考，线性对齐仍把重力当作自由向量求解。求解失败时拒绝惯性初始化，不把运动中的加速度平均值当成重力。OpenCV 的 +Y 向下只在还没有样本估计时作为初值。

`libs/pipelines/tracker_state_machine.h` 的重力重估周期仍是 `5e12` 纳秒，约 83 分钟，与 v1.33 相同。60 秒一次的完整重估会改写速度，没有保留。

联合先验里的速度信息保持各向同性 `(25, 25, 25)`。

## 留在代码里、本次测试未打开的开关

- `CUVSLAM_GRAVITY_VZ`：联合求解成功后，把竖直速度向视觉位移差修正，单次不超过 ±0.02 m/s。先前试验增大了竖直漂移，报告中的结果没有打开它。
- `CUVSLAM_GRAVITY_SCHEME=static`：用静止样本的重力替换参考方向，并把重力旋转设为单位阵。
- `CUVSLAM_GRAVITY_SCHEME=map`：在地图位姿上再做一次重力细化。
- `CUVSLAM_GRAVITY_SCHEME=tangent`：窗口求解之后沿重力切向作小步修正，单步约 0.02°，相对初始方向不超过 2°。
- `CUVSLAM_PGO_AUDIT`、`CUVSLAM_PGO_FROZEN`、`CUVSLAM_PGO_ABLATE`、`CUVSLAM_PGO_GRAPH` 只增加位姿图日志，不改变未设置这些变量时的优化结果。
