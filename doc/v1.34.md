# runtime_reduced v1.34

PGO verifies solver status and finite cost before accepting pose updates. Loop closure transports the PnP covariance into the relative edge's right-perturbation coordinates and rejects invalid covariance.

Bulk history export interpolates actual source-anchor corrections in timestamp order by default. It splits at missing anchors, frame gaps and non-increasing timestamps. Set `CUVSLAM_CONTINUOUS_SLAM_HISTORY=0` to select the preceding per-anchor export. Online odometry and PGO do not use this setting.
