# v1.37 数学、数值及信息传递修复

基于 release/runtime_reduced_v1.36（4aa5720）。这是一版已确认问题的修正，不是全部数学或统计模型正确性的证明。

## 发布默认

原始鱼眼分辨率，无人体 mask/额外裁剪；GPU Schur FP64，最多四关键帧；在线 VIO，回环/PGO 关闭；cam2 旋转预检；YAML 标定时移，额外 IMU 时移 0。条件视觉信息输出启用；源射线、几何不确定度实验关闭；导航初始化工程先验保留。

## 已确认并处理的问题

- Cauchy 代价 b log(1+c s) 对应导数 bc/(1+cs)、-bc²/(1+cs)²，旧实现缺失幅度系数。修正代价、导数口径，验证实际 GPU 目标与梯度。
- 惯性初始化 Hessian 仅存下三角；LM 预测下降使用对称视图，与实际求解一致。测试生产优化器，不仅测试辅助函数。
- 闭式预积分使用小角稳定级数和较大角解析 Gamma1/Gamma2。公式切换不是运动拒绝阈值。偏置雅可比通过独立 FP64 数值积分验证，没有误改已正确公式。
- 旋转正交化使用 double SVD 再转换；非有限输入不伪装为有效旋转。
- 鱼眼地图支持使用实际相机投影的像素距离，阈值保持不变。
- FP64 求解器的后验、点消元、QR、边缘化不经 float 回退；公共 API 和状态仍保留 float 边界。
- cuNLS 因子/损失及包装层逐层传播失败；求解失败不回写。初始化稀疏输出/PCG 工作区并避免 Thrust 元组填充读取。未把诊断填充字节读错误直接归因为实际漂移。
- 条件视觉信息按测量噪声和相对 IRLS 衰减计算；求解平均系数不改变测量信息尺度。正确处理位姿求逆、IMU 杆臂和切空间合同变换。
- 可选几何精化同时提交均值和消元信息，拒绝时均不回写。完整六组主对照不启用这一实验。

## 先验替换候选已撤回

固定地图条件下的视觉信息不能直接作为独立导航先验。本轮完整六组中四组退化；撤回该替换后，六组位姿、重力、时间戳与数学修正基线逐位一致。完整联合初始化协方差与历史地图—位姿相关性仍待建模，本版没有宣称既有高度误差已解决。

`ROOM_REPORT.md`、`ROOM_RESULTS.json` 是本轮六组真值对照；ATE 使用 SE(3) 不拟合尺度。`audit/` 为先前针对相同修复路径的公式与内存核查证据，日志内的实验库哈希不是最终发布库哈希。最终提交重建的 CTest、入口测试、库哈希和全程结果另存运行包 `release_validation/` 与 `manifest.json`。

内部无真值数据统计会在本分支追加。200730 的站立到坐姿是真实高度变化，不能以起终高度接近零作为验收规则。发布不使用真值拟合或速度裁剪改变输出。
