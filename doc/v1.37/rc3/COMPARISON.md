# rc2 与 rc3 对比

rc2提交为`b18815853c17ffc1c80742524e51b15ed55c41ee`；rc3对应新封存核心SHA256 `6c19a32afd35d42fc7bdfd4b9554fb10141afb5bf131e77fa3e4826c6b657970`。本轮是候选版本归档，不替换已有稳定版本。rc3默认关闭历史恢复和PGO，无掩模、原生鱼眼。

## 主要代码与模型差异

|环节|rc2|rc3|原因与边界|
|---|---|---|---|
|初始化到滑窗|旧导航工程先验及独立地图处理|联合导航、地图与2维重力平方根后验，保留交叉块和非零线性项|避免只传独立位姿信息后丢失地图/状态相关性；精度收益并不统一|
|在线更新|旧窗口更新路径|候选构图、优化、验收、提交及地图写回按同一后验状态管理|拒绝候选不消耗已提交历史；使用真实IMU积分区间|
|边缘化归属|旧窗口先验|观测键唯一、视觉/IMU consumed ledger、边界因子守恒|防止同一因子在活跃窗口与历史先验重复计入|
|旋转先验|旧坐标处理|先验专用连续旋转对数与流形雅可比转换|零角度处导数与非零公式极限一致；不替换原始IMU残差的全局对数函数|
|噪声与尺度|旧权重路径|预积分完整协方差白化、实际随机游走累计矩阵、显式像素噪声配置|rc3复验设置VIO_POSTERIOR_VISUAL_SIGMA_PX=1，保留这项明确配置，不宣称所有传感器噪声已重标定|
|前端补丁|旧仿射更新|CPU/GPU共享6列仿射模型、中心化均值导数、整补丁收敛；秩亏QR丢弃坐标清零|统一参数排列及退化解；不放宽匹配验收阈值|
|计算加速|旧求解路径|FP64 GPU QR/Gram/SPD，复用工作区、先验及线性化，块装配和BLAS|保持指定后验模型；不是仅把rc2相同模型换到GPU|
|历史恢复|无新增条件恢复|显式observed_history实验配置，默认关闭|只恢复有真实观测支持的点；15次审计使用前一a962核心，不能冒充rc3开关实验|
|工程封存|旧发布入口|精确前后端源码匹配、逐文件哈希、不可覆盖封存及新目录重建|从提交重建时复用封存静态依赖；共享包/驱动/Python依赖另记|

## 六组全程精度

原生512×512、无掩模、无PGO；SE(3)对齐、不改尺度；每个相机帧关联一次GT，位置线性插值+姿态SLERP、不外推、GT括号≤50ms。起终高度误差为真值覆盖首尾各1秒的竖直误差中位数之差。速度为未平滑相邻发布位置除以真实时间差。所有六组两版均为0失跟、0清图、0重力中断帧。GT覆盖不完整处不外推，不把完整帧数当成GT评价帧数。

room1、room3 ATE改善；room2、room4、room5、room6 ATE退化。room2/4高度改善不抵消XY退化；room5起终高度绝对误差变大。room6竖直RMSE从1.662cm降到0.809cm，XY从2.772cm升到5.831cm。因此rc3作为可追溯候选保存，不能宣布全面优于rc2。

room6同核心系统消融：联合后验开/补丁开XY=5.831cm，联合后验开/补丁关=5.879cm；后验关/补丁开=3.437cm，两者关=2.772cm。主要水平退化在完整联合后验路径；这不是固定因子图求解器对照，尚未区分初始化联合地图均值与滑窗先验的全部影响。

## 历史恢复归因与未完成工作

15次恢复属于a962前序核心同二进制开/关实验。每次固定输入复算的直接位姿差最大0.135mm；无新增恢复点观测时最大1.75nm。连续反馈最大XY差8.88cm，最大绝对Z差2.48cm。速度条件最优解、IMU时长及雅可比专项未发现异常小分母或时间距离用错。第12次恢复延长预算仍有0.867mm额外位移，未达严格驻点，但发生较晚，不能解释此前全部偏离。

原始历史非线性、精确无穷远、历史条件均值回代及其后续诊断原型不纳入rc3；参考求解尚未达到驻点，不能把其当前位姿当成准确答案。无单room阈值、无最大深度裁点、无输出速度裁剪或轨迹缩放。

## 证据和复现范围

ROOM_RESULTS.json保留ATE、RPE、XY/Z RMSE、GT覆盖、帧数、峰值速度、核心哈希。comparison.html内嵌六组完整轨迹/高度/速度原图。SOURCE_MANIFEST.json记录提交源码；QUALIFIED_PROVENANCE保留实际构建和专项验收记录。rc3/rebuild.py用于从本提交后端重新编译并复用封存静态依赖，不等于全项目从零构建。提交后新构建与回归记录写在共享盘rc3_release_20261127目录，不修改已有封存包。
