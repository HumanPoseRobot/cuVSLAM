多相机 PnP / VIO 滑窗一致性审计与 v1.35 全程对照
日期：2026-11-19

结论
本轮在独立目录完成了实际调用链审计、真实 CUDA/FP64 数值对照、边界失败重现和修复，以及六组原分辨率、关闭 PGO 的全程对照。实际多相机 GPU PnP 和滑窗未检出与 epipolar 优化相同的雅可比/位姿更新不一致或外参相机中心丢失。发现并修复的四项问题涉及无有效观测仍返回成功、拒绝时输出事务，以及 cuNLS LM 非有限增益的判断。
最终候选与本轮新跑的 v1.35 在全部六组共 18,643 帧的位姿、重力、时间戳上逐字节一致。输入哈希一致，最大位置差 0 m；没有失跟或初始化后的重力中断。因此这些修复提高边界可靠性，但本轮不能宣称改善了现有高度漂移。room5 的剩余竖直误差仍存在。

实际计算流程与坐标约定
重力初始化前：SolverSfMMultisensor -> ImuFusionContext::solve_visual -> pnp::MultisensorPoseEstimator -> cuNLS PnPFactorBatch / SE3StateBatch。
初始化后（本轮无深度 VIO）：solve_joint -> sba_imu::SolveGpuBiasRW -> gpu_vi::OptimizeGpu。该路径使用带局部坐标的加法状态和自动微分；不能把其更新规则直接套成 PnP 的 SE3 右乘。
关键帧滑窗：WindowBackend -> FP64 Schur -> 地图支持检查/调用者验收 -> 保留先验 -> pending -> commit -> 发布。
CPU PNPSolver 是其他模式的代码路径，并非本轮 Multisensor VIO 的实际前台。本轮也对它做了接口可靠性修复。
GPU PnP 优化 rig_from_world，使用右扰动；点投影包含 camera_from_rig * rig_from_world * Pworld。非零 camera_from_rig 平移会进入残差和雅可比。联合滑窗维护 world_from_imu 并使用完整 IMU/相机外参。

逐项检查与证据
1. GPU PnP 雅可比与更新：直接调用真实 SE3StateBatch::Plus 与 PnPFactorBatch::Evaluate，四相机非零旋转/中心、非单位世界姿态对照中心差分。最大绝对差约 0.000280（测试阈值 0.003），独立 Eigen 重投影也通过。未发现方向或相机中心项丢失。
2. 联合惯性/视觉因子：增加非零世界位置、姿态、局部旋转增量和四相机偏置测试，GPU 自动微分与双精度差分、独立投影通过。
3. 滑窗：非零姿态/中心的视觉项与先验独立 FP64 差分最大相对误差 1.8617e-8；3/4/6 状态 CPU/GPU 同图首步最大差分别为 1.28174e-15 / 4.88888e-15 / 5.40193e-15。没有发现本轮所检查的更新约定、中心或 FP64 Schur 装配错误。数值测试并不证明所有场景均无问题。
4. GPU PnP 无有效可见观测：cuNLS 会把相机后方点的残差/Jacobian 置零，旧包装器忽略求解摘要，仍返回成功并写信息矩阵，错误已用旧代码重现。修复增加有限/合法位姿、相机索引、观测/地图点检查，纯视觉分支检查已有设置要求的可见匹配支持，检查代价及候选；通过后才写输出。带 IMU/深度路径没有强制套用纯视觉支持数量门槛。
5. CPU PnP 无地图匹配：原始观测数足够但没有有效地图点时，旧零代价快路径误报成功。修复以有效可见匹配点验收，检查分解/步长和有限值，用局部候选，成功才写回。旧失败已重现，新测试通过。
6. 滑窗晚期拒绝仍改写 result：旧代码在地图支持、调用者验收和保留先验完成前赋值 result。强制晚期拒绝可重现返回 false 但输出改变。修复改为全部检查和 pending 准备成功后才赋值。本轮 room2/room5/room6 分别观察到 63/239/13 次该类晚期拒绝（前后三组内部数据为 0）；原实际调用者已丢弃失败时的临时候选，所以旧接口问题没有在这六组改变已发布轨迹。地图提交原有先验/状态事务检查保留。
7. cuNLS LM 非有限增益：原 RejectStep(NaN) 和 AcceptStep(NaN) 都返回 false，外层仍可能落入拷贝试探状态的分支，+Inf 也可能接受。增加显式 finite 检查，非有限质量拒绝且按原有范围上调阻尼。修复范围是 LM 普通试探的验收分支；原收敛分支仍按其已有单调代价规则处理。通过真实控制器测试重现旧失败，新测试通过。单测故意输入 NaN/+Inf/-Inf 时记录 3 次标记，证明日志通路工作；最终六组开启 Error 日志，实际标记 0 次。

逐文件改动与原因（完整 diff 见 fix_lm.patch）
cmake/ext/cunls.cmake：将非有限 LM 增益补丁接入可重复的依赖补丁过程，防止只修改本机依赖造成不可复建。
cmake/ext/cunls_lm_quality.patch：实现 LM finite 验收与拒绝日志；不改目标函数或正常停止条件。
libs/pnp/multisensor_pose_estimator.cpp：实际 GPU PnP 的输入、可见支持、摘要与候选验收，延后输出提交；增加可选 Error 日志开关。
libs/pnp/multicam_pnp.cpp：CPU PnP 有效支持、有限值/分解检查、失败保持输出。
libs/pnp/test/multisensor_pose_estimator_test.cpp：实际 CUDA Plus/Jacobian、相机后方/无匹配失败、非法输入保持输出、LM NaN/Inf 验收测试；原空惯性输入失败测试改为要求保持调用者输出。
libs/pipelines/gpu_window/window_backend.cpp：延后 result 赋值，拒绝不修改输出；其他差异为格式和版权规范整理。
libs/pipelines/gpu_window/window_commit_test.cpp：真实合成滑窗走到晚期调用者拒绝，检查 pose/velocity/info、地图和 pending 状态不变。
libs/pipelines/gpu_window/gpu_bias_rw_test.cpp：非零姿态、中心、局部增量和完整四相机外参的 AD/独立投影测试。
libs/pipelines/gpu_window/window_test.cpp：非零姿态的视觉/先验差分与 3/4/6 状态 CPU/GPU FP64 首步对照。
libs/pipelines/imu_fusion_context.cpp：增加预测、视觉前台、滑窗候选/接受、速度、偏置和世界重力诊断；其余大段 diff 为规范格式整理。未调整 IMU 权重、端点、积分模型、偏置约束、初始化条件或高度约束。

指标口径
height_change_m：沿首次有效重力得到的固定世界向上方向，最后 1 秒高度中位数减最初 1 秒中位数，是高度变化，不是真值高度误差。
peak_speed_mps：相邻有效发布位姿的欧氏位移除真实时间差，未平滑；不是优化器内部速度状态。
ATE：沿用 replay_truth.py 保存的 metrics.json，在既有时间关联下做 SE(3) 刚性对齐，不做尺度校正。该评估对真值采样；关联量和覆盖率都在 comparison_lm.json 保留。
另列 median_endpoint_height_error_m：相机帧与最近真值 <=20ms 关联，SE(3) 位置对齐后，末 1 秒竖直误差中位数减首 1 秒中位数。它与上一项 ATE 采样权重不同，不能混作同一量。相机帧采样 ATE 也保存在 JSON。
room5 saved metrics 的密集真值首尾样本高度误差为 -0.246863m；相机帧首尾 1 秒中位数误差为 -0.194068m。二者定义不同，均在 v1.35 与候选之间完全相同，不能解读为本次退化。

room5 剩余竖直偏差：证据与边界
按相机采样、SE(3) 对齐误差，以超过阈值持续至少 1 秒作为诊断条件（不参与求解验收）：
零基帧 201 / 10.050286s，首次持续超过 2cm，误差 -2.269cm；首次有效重力为帧325 / 16.250646s。这表明部分持续偏差在惯性初始化前已存在，但不能排除初始化后的进一步累积。
帧768 / 38.401396s，首次持续超过5cm：预测 -4.9372cm，视觉前台 -5.01294cm，最终发布 -5.01282cm。该帧约 -0.757mm 来自前台，主要误差已在预测继承状态中，当前窗口改变量很小。
帧1570 / 78.502315s，首次持续超过10cm：预测 -10.2489cm，前台 -10.3651cm，发布 -10.3658cm。
正常前台诊断覆盖2519帧，窗口诊断485条，其中接受239次；接受窗口沿重力方向修正的代数和 +1.399cm，单次最大绝对值1.289cm。该代数和不能当成闭环反馈系统中窗口独立造成的总误差。
在观测到的初始化后正常前台分支，世界重力向量变化0；用首个匹配真值姿态独立定向，初始重力倾角约0.304度。未发现重力随头部旋转绑定的证据。小倾角仍可能随积分影响竖直位移，不能只由该角度排除其累计作用。
前台分解日志并非覆盖所有降级/纯惯性分支。最早持续偏差是对当前整段刚性对齐后的描述，不是证明某帧起首次产生了因果错误。
因此本轮排除了所测试路径上的更新约定、相机中心与失败输出污染作为这六组既有差异的直接解释，但没有解决 room5 剩余漂移。下一步若继续，应固定真实观测/地图和连续初值，对纯视觉状态进入初始化、初始化输出、预测继承与偏置/先验做可重复单项替换；不能只凭当前继承误差把原因归给 IMU。
